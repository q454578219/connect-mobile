Architecture

它是怎么工作的

整条链路里没有 ffmpeg，没有 minicap 依赖，也没有往手机里推任何二进制：采集用系统自带的 screenrecord，解码用 Chromium 内置的 WebCodecs 硬解，控制用 adb shell input。

为什么不用 minicap它依赖的 SurfaceComposerClient::getBuiltInDisplay 在 Android 10 起被系统删除，任何版本的 minicap.so 都加载不起来。所以 Android 10+ 走 screenrecord，旧系统才回退 minicap。
为什么必须转 AVCCWebCodecs 给了 description(avcC) 之后，每帧必须带长度前缀；喂起始码格式会直接报 "Unable to determine size of bitstream buffer"。
为什么滚轮要节流每次 adb shell input 都是新起一个进程，Windows 上开销 50–150ms。滚轮高频触发必须累积增量 + 冷却，否则进程越滚越堆。
Features

能干什么

🖥

实时投屏

H.264 画面，USB 下真机实测 100+ fps。静止画面不产帧属于 H.264 的正常行为。

📶

免线连接

同一 WiFi 下连一次就不用插线。Android 11+ 支持配对码，老系统支持「USB 转无线」一键切换。

👆

像素级点击

点哪打哪。坐标按画面尺寸与设备分辨率缩放换算，不会偏到左上角 1/4 区域。

🖱

滚轮当手指

滚轮自动合成为上滑/下滑，翻列表不用按住拖。左右滚轮 = 翻页。

⌨️

键盘直输

电脑键盘直接打字到手机（ASCII）。打字捕获时手势热键自动让路，数字照常输入。

1️⃣

四向手势热键

小键盘 1/2/3/4（顶排数字也行）= 左/右/上/下滑，和屏幕方向一致。

🔙

导航键条

返回 / 桌面 / 最近任务 / 音量 ± / 电源，全部在画面下方一排。

🌙

息屏投屏

把手机亮度压到最低并延长锁屏，夜里不刺眼，投屏不中断；退出自动还原。

🌓

画面遮罩

黑夜 / 护眼 / 自定义色调，可只染画面也可染满整个窗口，只影响电脑显示。

🪟

可收起的侧栏

侧栏边缘可拖拽调宽；收起时能把窗口缩成贴合画面的小窗（scrcpy 风格）。

🔍

分辨率可调

360 / 540 / 720 / 1080 / 原始。720 是清晰度与流畅度的平衡点。

🧪

有测试

22 个单元测试（H.264 解析、minicap 协议、坐标换算、文本转义）+ 5 个真机 e2e 脚本。

Scope & limits

边界在哪里，为什么不做网页版

这一节是刻意写清楚的：这个作品的形态是桌面应用，不是网页，也不是小程序。原因不是懒得改，而是它的三根支柱浏览器都拿不到。

它做不到的事

  • 只支持 Android。iOS 要 libimobiledevice + WebDriverAgent，是另一套架构。
  • 中文输入不支持：adb input text 只收 ASCII，中文请用手机自己输入法。
  • 画面有变化才产帧，静止时帧率统计会掉到 0。
  • 息屏投屏是「最低亮度」方案，背光仍开着，省电有限，价值是夜里不刺眼。
  • 无线模式延迟与画质受 WiFi 带宽影响，建议 720p 以下。
  • 只在 Windows 10 / 11 上验证过并打包（NSIS 安装包）。

为什么交不出网页版 / 小程序版

  • 要起子进程：全流程靠 resources/tools/adb.exe 干活，浏览器没有 child_process，也没有本地文件系统。
  • 要摸 USB：投屏与点击都建立在 USB 调试通道上，小程序连 TCP 直连都受限。
  • 要安全上下文：WebCodecs 的 VideoDecoder 只在安全上下文可用，data: 页面里直接是 undefined。
  • 理论上存在一条路：Chrome 的 WebUSB + 用 JS 重写一遍 ADB 协议（ya-webadb 那种），但那等于把 adb / devices / screenrecord / input / wireless 五个模块全部重写，且只有 Chrome、必须 HTTPS、小程序依然无解。
  • 所以本作品以 Windows 桌面应用形态交付，本页面是它的交互演示与说明，不是产品本体。

手机端准备（4 步）

  1. 设置 → 关于手机 → 连点「版本号」7 次，开启开发者选项
  2. 开发者选项 → 打开「USB 调试」
  3. 插上 USB 线，手机上点「允许 USB 调试」→ 勾选「一直允许」
  4. 部分国产 ROM 还要额外打开「USB 调试（安全设置）」，否则点击无效

连好后在应用里选中设备 → 选投屏宽度 → 点「开始投屏」。想免线就点右上角「无线连接」。
